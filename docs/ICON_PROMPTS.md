# Icon prompts for ChatGPT image generation

Use these to generate the game's icons in ChatGPT. When you send me the PNG files, I put them into the game.

## How to get a consistent set

1. **Stay in one chat.** Generate every icon in the same ChatGPT conversation so the style carries over.
2. **Start with the style prompt** (below) and the first icon. Regenerate until you love the style.
3. **Then say "same style" for every next icon**, using the short lines in the list. If the style drifts, attach your favourite icon and write "match this icon's style exactly".
4. **One icon per image.** Sheets with many icons come out uneven and are hard to cut apart.
5. **Ask for a transparent background.** If ChatGPT gives a white or checkered background instead, ask "make the background truly transparent, PNG". If it still fails, send it anyway and I remove the background.
6. **Download as PNG, 1024x1024.** Name each file with the name in the list (for example `speed.png`). I shrink them to the sizes the game needs.

## 1. Style prompt (paste first, with the first icon)

```
I am making a set of game icons for a bright cartoon 3D obby/simulator game for kids and teens. I need every icon in exactly the same style, so remember this style for the whole conversation:

STYLE: chunky 3D cartoon game icon, like the item icons in top mobile and Roblox-style simulator games. One single object, centred, filling about 80% of the square, slightly tilted for energy. Thick dark navy outline (#1B1736) around the whole object. Smooth glossy toy-like plastic look: bright saturated colours, soft gradient from light at the top to deeper colour at the bottom, one clear white shine highlight on the upper left, a slightly darker shadow edge on the lower right. Rounded, puffy, simple shapes with very little small detail, so it still reads at 32 pixels. Front three-quarter view. No text, no letters, no numbers, no background, no frame, no ground shadow.

OUTPUT: square 1024x1024 PNG with a fully transparent background.

First icon: a red high-top sneaker with a white sole and white toe cap, with a small yellow wing on the heel and two white speed lines behind it. It means "Run Speed".
```

## 3. Fix-up phrases

- "Make the outline thicker and darker navy."
- "Simpler. Remove small details so it reads when tiny."
- "Brighter and more saturated, like a glossy toy."
- "Match the first icon's style exactly: same outline weight, same lighting, same shine."
- "Centre the object and make it fill more of the square."
- "Remove all text, letters and numbers."
- "Make the background fully transparent."

## 4. Rules to keep

- No real brands, no logos, no characters from other games.
- No text inside any icon. The game adds its own labels.
- Keep every icon as one object. Scenes with backgrounds do not work as icons.

## 5. What to send back

Send me the PNG files with the names above. You do not need all of them at once: the 5 shop upgrades, the 7 side buttons and the 6 money and top-bar icons are the ones players see most. Any icon you do not send keeps its current drawing.
